# Spec Delta

## Purpose

작업의 예상 기간과 의존 관계로 예상 총 기간과 핵심 경로를 계산해, 어떤 작업이 전체 일정에 영향을 주는지 사용자가 판단할 수 있게 한다.

## ADDED Requirements

### Requirement: 예상 총 기간 계산
The system SHALL 프로젝트 시작을 0으로 두고 모든 작업의 가장 이른 완료 값 중 최댓값을 예상 총 기간으로 계산한다. 예상 기간은 영업일이 아닌 연속된 일 단위로 취급한다. 작업이 없으면 0이다.

#### Scenario: 선형 작업
- **WHEN** 기간 2, 3, 4인 작업이 A → B → C로 연결되어 있다
- **THEN** 예상 총 기간은 9이다

#### Scenario: 병렬 작업
- **WHEN** 기간 2인 A 뒤에 기간 5인 B와 기간 3인 C가 각각 이어지고, 기간 1인 D가 B와 C를 모두 기다린다
- **THEN** 예상 총 기간은 8이다

#### Scenario: 경계 사례
- **WHEN** 작업이 없는 프로젝트와 기간 3인 작업 1개뿐인 프로젝트를 분석한다
- **THEN** 예상 총 기간은 각각 0과 3이다

### Requirement: 작업별 일정 값 계산
The system SHALL 작업마다 ES, EF, LS, LF, 여유 기간을 계산한다. EF = ES + 기간, LS = LF - 기간, 여유 기간 = LS - ES이며, 후속 작업이 없는 작업의 LF는 예상 총 기간이다.

#### Scenario: 여유 기간이 있는 작업
- **WHEN** 기간 2인 A 뒤에 기간 5인 B와 기간 3인 C가 각각 이어지고, 기간 1인 D가 B와 C를 모두 기다린다
- **THEN** C의 ES는 2, EF는 5, LS는 4, LF는 7, 여유 기간은 2이다

#### Scenario: 독립된 작업 묶음
- **WHEN** 기간 5인 A와 선후 관계가 없는 기간 2인 B가 있다
- **THEN** 예상 총 기간은 5이고 A의 여유 기간은 0, B의 여유 기간은 3이다

### Requirement: 복수 핵심 경로 처리
The system SHALL 여유 기간이 0인 작업을 핵심 작업으로, 양 끝이 핵심 작업이고 앞 작업의 EF와 뒤 작업의 ES가 같은 연결을 핵심 연결로 표시한다. 핵심 경로가 여러 개면 모두 표시한다.

#### Scenario: 동일 길이의 두 경로
- **WHEN** 기간 2인 A 뒤에 기간 3인 B와 기간 3인 C가 각각 이어지고, 기간 1인 D가 B와 C를 모두 기다린다
- **THEN** A, B, C, D가 모두 핵심 작업이고 네 연결이 모두 핵심 연결이다

#### Scenario: 핵심 작업 사이의 비핵심 연결
- **WHEN** A → B → C 경로와 A → C 직접 연결이 함께 있다
- **THEN** A → C 연결은 핵심 연결로 표시되지 않는다

### Requirement: 변경 시 자동 재계산
The system SHALL 작업의 기간, 작업 추가·삭제, 의존 관계가 바뀌면 일정 분석을 즉시 다시 계산하며, 상태 변경은 계산 값에 영향을 주지 않는다.

#### Scenario: 기간 변경 영향
- **WHEN** 사용자가 여유 기간이 있는 작업의 기간을 여유 기간보다 길게 늘린다
- **THEN** 예상 총 기간과 핵심 경로가 새 값으로 바뀐다

#### Scenario: 작업 완료
- **WHEN** 사용자가 작업을 완료로 변경한다
- **THEN** 예상 총 기간과 작업별 일정 값은 바뀌지 않는다

### Requirement: 일정 분석 화면과 계산 한계 안내
The system SHALL 예상 총 기간, 시작일 기준 예상 종료일, 핵심 작업, 작업별 여유 기간을 표시하고, 입력된 기간과 의존 관계로 계산한 예상 일정이며 휴무일·인력·실제 완료일을 반영하지 않는다고 안내한다.

#### Scenario: 예상 종료일
- **WHEN** 시작일이 2026-12-01이고 예상 총 기간이 9일인 프로젝트의 일정 분석을 연다
- **THEN** 예상 총 기간 9일과 예상 종료일 2026-12-09가 표시된다

#### Scenario: 계산 한계 안내
- **WHEN** 사용자가 일정 분석 화면을 연다
- **THEN** 계산 결과가 예상 일정이며 반영되지 않는 요소가 있다는 안내를 볼 수 있다

#### Scenario: 분석할 작업이 없음
- **WHEN** 작업이 없는 프로젝트의 일정 분석을 연다
- **THEN** 오류 없이 작업을 추가하라는 빈 상태 안내가 표시된다
