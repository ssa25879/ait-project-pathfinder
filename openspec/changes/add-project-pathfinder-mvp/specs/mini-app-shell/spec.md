# Spec Delta

## Purpose

다섯 개 화면의 이동 구조와 앱인토스 비게임 출시 가이드가 요구하는 공통 동작을 정의해, 앱 전체가 일관되게 작동하고 검수 기준을 충족하도록 한다.

## ADDED Requirements

### Requirement: 화면 구성과 이동
The system SHALL 프로젝트 홈, 프로젝트 상세, 작업 편집, 경로도, 일정 분석 화면을 제공하고, 프로젝트 상세에서 경로도와 일정 분석으로 이동할 수 있게 한다.

#### Scenario: 분석 화면 이동
- **WHEN** 사용자가 프로젝트 상세에서 경로도 또는 일정 분석을 선택한다
- **THEN** 같은 프로젝트의 해당 화면이 열린다

### Requirement: 뒤로가기 동작
The system SHALL 내비게이션 바의 뒤로가기와 Android 시스템 백버튼을 모든 화면에서 이전 화면으로 이동하게 하고, 최초 화면에서는 미니앱을 종료하게 한다. 내비게이션 바의 뒤로가기와 자체 구현한 뒤로가기를 동시에 노출하지 않는다.

#### Scenario: 하위 화면에서 뒤로가기
- **WHEN** 작업 편집 화면에서 뒤로가기를 누른다
- **THEN** 이전 화면으로 돌아간다

#### Scenario: 최초 화면에서 뒤로가기
- **WHEN** 프로젝트 홈에서 Android 시스템 백버튼을 누른다
- **THEN** 미니앱이 종료된다

### Requirement: 앱인토스 내비게이션 바 사용
The system SHALL 앱인토스 내비게이션 바를 사용하며 자체 로고를 추가하지 않는다. 앱 정보에 등록한 국문 이름은 "프로젝트 경로도"로 표시한다.

#### Scenario: 상단 영역
- **WHEN** 미니앱의 임의 화면을 연다
- **THEN** 앱인토스 내비게이션 바가 표시되고 콘텐츠가 그 아래에 겹치지 않게 놓인다

### Requirement: 라이트 테마
The system MUST 기기가 다크 모드여도 라이트 테마로 표시한다.

#### Scenario: 기기 다크 모드
- **WHEN** 기기가 다크 모드인 상태에서 미니앱을 연다
- **THEN** 모든 화면이 라이트 테마로 읽기 쉽게 표시된다

### Requirement: 제스처 확대 비활성화
The system MUST 모든 화면에서 제스처 확대·축소를 비활성화한다.

#### Scenario: 경로도 핀치
- **WHEN** 사용자가 경로도 화면에서 핀치 동작을 한다
- **THEN** 화면이 확대되거나 축소되지 않는다

### Requirement: 진입 시 강제 표시 금지
The system MUST 미니앱 진입 직후 바텀시트나 안내를 자동으로 띄워 사용자의 동작을 막지 않는다.

#### Scenario: 첫 실행
- **WHEN** 사용자가 처음 미니앱을 연다
- **THEN** 바텀시트 없이 프로젝트 홈의 빈 상태와 프로젝트 추가 동작이 바로 표시된다

### Requirement: 빈 상태와 오류 상태
The system SHALL 프로젝트나 작업이 없을 때 다음 행동을 안내하고, 존재하지 않는 프로젝트나 작업 화면으로 이동하면 오류 안내와 프로젝트 홈으로 돌아가는 동작을 표시한다.

#### Scenario: 프로젝트 없음
- **WHEN** 프로젝트가 하나도 없는 프로젝트 홈을 본다
- **THEN** 프로젝트 추가를 안내하는 빈 상태가 표시된다

#### Scenario: 삭제된 대상
- **WHEN** 존재하지 않는 작업의 편집 화면으로 이동한다
- **THEN** 대상을 찾을 수 없다는 안내와 프로젝트 홈으로 돌아가는 동작이 표시된다

### Requirement: 모바일 사용성과 네트워크 독립
The system SHALL 폭 360px 이하의 화면에서도 가로로 잘리는 입력이나 버튼 없이 작동하고, 터치 후 2초 안에 반응하며, 네트워크 연결 없이 핵심 기능을 제공한다.

#### Scenario: 좁은 화면
- **WHEN** 폭 320px 화면에서 작업 편집 화면을 연다
- **THEN** 모든 입력과 저장 버튼을 가로로 잘림 없이 사용할 수 있다

#### Scenario: 오프라인 사용
- **WHEN** 이미 열린 미니앱에서 네트워크가 끊긴 뒤 작업 상태를 변경한다
- **THEN** 변경과 재계산이 정상적으로 동작한다

### Requirement: 화면 가독성과 쉬운 용어
The system SHALL 모든 화면에서 본문을 15px 이상, 메타 정보를 13px 이상으로 표시하고, 누르는 요소에 44px 이상의 터치 영역을 제공한다. 화면 문구에는 `design.md` 12장의 화면 용어를 사용한다.

#### Scenario: 글자 크기
- **WHEN** 폭 320px 화면에서 경로도와 일정 분석을 연다
- **THEN** 13px 미만의 글자가 표시되지 않는다

#### Scenario: 쉬운 용어
- **WHEN** 사용자가 작업 편집 화면을 연다
- **THEN** 선행 작업 대신 먼저 끝낼 작업이라는 항목명과 설명이 표시된다
